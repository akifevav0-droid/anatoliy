# Дизайн-система сайтов Анатолия Шабаршова — версии 1, 2, 7 (06.10.2026)

Одна система — три темы. Устройство страниц общее, разный только характер.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `система/ядро.css` | Все компоненты. Цвета, шрифты, размеры и отступы — только через переменные. |
| `система/ядро.js` | Меню, окна записи и оплаты, ролики, карта сертификата, видео, нижняя кнопка, появление блоков. |
| `система/основа.html` | Общий каркас страницы: шапка, подвал, окна. |
| `система/движок.py` | Сборщик. Делает неразрывные пробелы и нарезку картинок, проверяет файлы. |
| `система/проверка.js` | Автопроверка в браузере. Заодно замеряет места картинок для `размеры.json`. |
| `vN/тема.css` | Характер версии: значения переменных и несколько своих правил. |
| `vN/src/*.html` | Тексты и порядок блоков версии. |
| `vN/собрать.py` | Настройки версии: страницы, кнопки, шапка. |

**Как собрать и выложить:** `bash выложить.sh "что изменилось"`.
Собрать без выкладки: `NOPUSH=1 bash выложить.sh`.

## Правила для всех версий

1. **Шрифт — ровно 7 размеров:**
   - `--t-display` — главный заголовок;
   - `--t-h2`;
   - `--t-h3`;
   - `--t-lead`;
   - `--t-body`;
   - `--t-small`;
   - `--t-caps`.

   Числа у каждой темы свои, имена общие. Цифры цен — это `--t-h2`, номера шагов — `--t-h3`. Отдельных размеров нет.
2. **Отступы — одна шкала:** 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 (`--sp1…--sp8`). Из неё построены:
   - секция `--sec`;
   - поля страницы `--pad`;
   - промежуток в сетке `--gap`;
   - промежуток между колонками `--col`.
3. **Цвет — только переменные.** Набор у всех тем один:
   - `--ink`, `--ink-2`, `--mute` — текст;
   - `--line` — линии;
   - `--bg`, `--alt`, `--alt-2` — фоны;
   - `--dark` — тёмный блок;
   - `--accent` — акцент;
   - `--btn-*` — кнопки.
4. **Фото — только в рамке `.ph` с пропорцией:** `r16x9`, `r4x5`, `r1x1`; `r9x16` — только для вертикальных роликов. Внутри `object-fit: cover`, поэтому фото не растягивается и края ровные. Текст на фото не кладём.
5. **Картинки нарезает сборщик.** Пишем просто `<img src="assets/…jpg" alt="…">`. Сборщик сам:
   - делает `<picture>` с WebP и JPG в ширинах 400 / 640 / 960 / 1280 / 1600 / 1920 (папка `assets/r/`);
   - ставит `width` и `height`, чтобы страница не прыгала при загрузке;
   - ставит `sizes` по замерам в `система/размеры.json`, чтобы браузер брал нужную ширину, а не самую большую;
   - грузит первую картинку страницы сразу, остальные — по мере прокрутки.
6. **Видео не грузится, пока его не видно** (`data-src`). Под ширину экрана берётся свой файл:
   - телефон — `data-src-m`;
   - до 1440 px — `data-src-l`;
   - больше — `data-src`.
   Ролики по нажатию открываются на весь экран со звуком.
7. **Прокрутка — обычная, браузерная.** Перехват колёсика и Lenis убраны: от них страница подтормаживала.
8. **Стилей прямо в разметке нет.** Всё — в ядре или в теме.

### Состояния
- **Кнопка:** наведение (цвет); фокус с клавиатуры (обводка `--accent`); `aria-disabled` (бледная, не нажимается: «Перейти к оплате» без галочки).
- **Окна:** открываются плавно, закрываются по фону, крестику и Esc. Фокус возвращается на кнопку, которой окно открыли. Пока окно открыто, страница не прокручивается.
- **Карта:** нажатие или Enter переворачивают её (`aria-pressed`). Наклон и блик — только мышью и только если в системе не включено «уменьшить движение».
- **Включено «уменьшить движение»:** анимации и появление блоков отключены, фразы не сменяются.

## Проверка перед выкладкой
`система/проверка.js` проходит все страницы трёх версий на ширинах 360, 390, 768, 1024, 1440 и 1920. Норма по каждому пункту — 0:
- сдвиг вбок;
- элементы за краем экрана;
- битые картинки;
- растянутые картинки;
- картинки, которые грузятся в 2,5 раза больше места и более;
- картинки мельче своего места («мыло»);
- обрезанные кнопки;
- ошибки скриптов.

Плюс на каждой странице должно быть не больше 7 размеров шрифта.
